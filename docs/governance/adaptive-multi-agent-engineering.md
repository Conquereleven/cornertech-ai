# AMAE · Agent selection reference

[Execution Standard 1.1](execution-standard.md) is the daily operating policy. Choose the minimum qualified agents for the outcome:

- **SOLO:** default for ordinary development, including functional code, UI, fixes and tests.
- **DUAL:** one implementer plus a distinct reviewer when material risk or an applicable control justifies independent review. Review the actual artifact and relevant evidence at the exact SHA.
- **SPECIALIZED:** add a specialist only when a verified capability is needed; one DRI and clear ownership remain.

Required reviews, safety boundaries, provider/data permissions and separate external-action approvals remain in force. If an agent is unavailable, proceed with other authorized work. No orchestrator, fixed model pairing, registry or pilot is a routine-task prerequisite.
